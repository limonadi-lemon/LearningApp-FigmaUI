# 📚 Learning App UI (Figma)

A modern vocabulary learning application designed with **Figma**.

This project focuses on creating a simple, clean and enjoyable learning experience for language learners.

---

## ✨ Overview

Learning App is a mobile application concept that helps users memorize vocabulary through interactive flashcards and mini games.

The interface is designed with a soft color palette and minimal style to make learning more comfortable.

---

## 🎨 Features

- 🌿 Minimal & clean interface
- 📖 Interactive flashcards
- 🔄 Flip card animation
- 👉 Swipe right → Remember
- 👈 Swipe left → Review
- 🎮 Mini Games page
- 📈 Learning progress
- 📱 Mobile-first design
